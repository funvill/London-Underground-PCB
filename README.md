# London-Underground-PCB

A decorative PCB with 600 individually addressable RGB LEDs arranged in the London Underground map layout. Animated trains travel along each tube line using official TfL line colors.

[PCB Preview](https://kicanvas.org/?github=https://github.com/funvill/London-Underground-PCB/tree/main/hardware) via kicanvas
